# Begrippenlijst (Glossary) ✏️

Elk item in de begrippenlijst is ook een Tooltip. Het woord of de zin wordt herhaald tussen haakjes om mensen die Google Translate gebruiken te helpen.

Wanneer Google Translate is geselecteerd:

* Tooltips, aangegeven door onderbroken onderstreping, blijven in het Engels weergegeven
* Op de Begrippenlijstpagina
    * Het eerste exemplaar (in vet) blijft in het Engels
    * Het tweede exemplaar (tussen haakjes) wordt vertaald naar uw geselecteerde taal

**<span translate="no">API</span>**&nbsp; (API): Application Programming Interface

**<span translate="no">APN</span>**&nbsp; (APN): Apple Push Notification service

**<span translate="no">App Group</span>**&nbsp; (App Group): een unieke identifier die Apple gebruikt voor een bepaalde app, de uwe heeft uw TEAMID erin ingebed

**<span translate="no">BLE</span>**&nbsp; (BLE): Bluetooth low energy, gebruikt voor communicatie door telefoons, CGM en sommige pompen

**<span translate="no">branch</span>**&nbsp; (branch): versie van code binnen een enkel repository of workspace repository

**<span translate="no">CAGE</span>**&nbsp; (CAGE): canule (of pomp site) leeftijd op Nightscout site

**<span translate="no">Certificate</span>**&nbsp; (Certificate): Apple certificaat wordt gebruikt om uw iOS of Mac apps te ondertekenen - gekoppeld aan maar verschillend van uw permanente Developer ID

**<span translate="no">CGM</span>**&nbsp; (CGM): continue glucose monitor, draagbaar medisch hulpmiddel dat glucose in interstitiële vloeistof meet en rapporteert

**<span translate="no">clone</span>**&nbsp; (clone): maak een kopie van een repository op uw computer inclusief revisiegeschiedenis en mogelijkheid om bij te werken met git commando's

**<span translate="no">COB</span>**&nbsp; (COB): Carbs on Board (Koolhydraten aan Boord), beïnvloedt geautomatiseerde insulinetoediening

**<span translate="no">commit</span>**&nbsp; (commit): een formele wijziging aan bestanden in een repository; elke commit heeft een alfanumerieke identifier (SHA-1)

**<span translate="no">Correction Factor</span>**&nbsp; (Correction Factor): hoeveel punten uw bloedsuiker zal dalen voor elke eenheid insuline

**<span translate="no">CR</span>**&nbsp; (CR): Carb Ratio (Koolhydraatratio); hoeveel gram koolhydraten worden gedekt door één eenheid snelwerkende insuline

**<span translate="no">DIA</span>**&nbsp; (DIA): Duration of Insulin Action (Werkingsduur van Insuline), de volledige tijd dat insuline actief is inclusief een lange, lage-niveau staart

**<span translate="no">DIY</span>**&nbsp; (DIY): Do it yourself (Doe het zelf), een veelgebruikt acroniem voor de open-source softwaregemeenschap (en de maker gemeenschap)

**<span translate="no">fork</span>**&nbsp; (fork): een kopie van code in een github repository anders dan het origineel

**<span translate="no">GIF</span>**&nbsp; (GIF): Graphics Interchange Format (GIF) kan worden gebruikt voor kleine animaties en lage-resolutie videoclips

**<span translate="no">git</span>**&nbsp; (git): een tool voor versiebeheer

**<span translate="no">GitHub</span>**&nbsp; (GitHub): een online service voor het opslaan van repositories, toegankelijk vanaf een browser

**<span translate="no">github.com</span>**&nbsp; (github.com): een online service voor het opslaan van repositories, toegankelijk vanaf een browser

**<span translate="no">Glucose Chart</span>**&nbsp; (Glucose Chart): Weergave van gemeten en voorspelde glucosewaarden

**<span translate="no">GMT</span>**&nbsp; (GMT): Greenwich Mean Time is gemiddelde zonnetijd op 0 graden lengtegraad, zie UTC

**<span translate="no">Guardrails</span>**&nbsp; (Guardrails): limieten in de code voor door gebruiker geselecteerde instellingen, aanbevolen en absolute limieten worden gegeven

**<span translate="no">Hamburger Menu</span>**&nbsp; (Hamburger Menu): drie parallelle lijnen die, wanneer aangeraakt, een nieuw menu openen

**<span translate="no">Identifiers</span>**&nbsp; (Identifiers): namen van modules gevonden op uw Apple Developer Identifiers pagina die vereist zijn voor GitHub build methode

**<span translate="no">IOB</span>**&nbsp; (IOB): Insulin on Board (Insuline aan Boord), beïnvloedt geautomatiseerde insulinetoediening: de huidige actieve insuline (boven of onder de basaalstand)

**<span translate="no">iOS</span>**&nbsp; (iOS): besturingssysteem gebruikt door Apple mobiele apparaten (iPhone, iPod, iPad)

**<span translate="no">ISF</span>**&nbsp; (ISF): Insulin Sensitivity Factor (Insuline Gevoeligheidsfactor); hoeveel punten uw bloedsuiker zal dalen voor elke eenheid insuline; soms Correction Factor genoemd

**<span translate="no">Issue</span>**&nbsp; (Issue): Op github - een formele methode om een probleem te rapporteren, ofwel codegedrag of documentatie

**<span translate="no">JSON</span>**&nbsp; (JSON): JavaScript Object Notation; een standaard data-uitwisselingsformaat dat op tekst gebaseerd en menselijk leesbaar is

**<span translate="no">macOS</span>**&nbsp; (macOS): besturingssysteem voor Mac computer

**<span translate="no">Loop</span>**&nbsp; (Loop): Met een hoofdletter L, Loop is één van verschillende doe-het-zelf kunstmatige pancreas systemen

**<span translate="no">Match-Secrets</span>**&nbsp; (Match-Secrets): een privé repository die u moet aanmaken in uw github account, slaat sleutels op die nodig zijn om te bouwen met github Build Actions

**<span translate="no">MTB</span>**&nbsp; (MTB): Manual Temporary Basal: door gebruiker geïnitieerde tijdelijke basaal, Omnipod Common functie

**<span translate="no">MDT</span>**&nbsp; (MDT): veelgebruikte afkorting voor Medtronic pompen

**<span translate="no">modal</span>**&nbsp; (modal): bericht of waarschuwing verschijnt voor app die moet worden erkend om terug te keren naar app

**<span translate="no">NFC</span>**&nbsp; (NFC): Near-Field Communication wordt gebruikt voor het scannen van apparaten zoals Libre sensoren

**<span translate="no">Nightscout</span>**&nbsp; (Nightscout): een persoonlijke website gebruikt om uw glucose en diabetesmanagementgegevens te bekijken.

**<span translate="no">Omnipod</span>**&nbsp; (Omnipod): Insulet slangloos insuline pomp

**<span translate="no">PR</span>**&nbsp; (PR): Pull Request - een formele methode om wijzigingen aan een repository aan te vragen

**<span translate="no">Provisioning Profile</span>**&nbsp; (Provisioning Profile): koppelt uw app aan uw Developer ID en beperkt app levensduur tot 1 jaar (betaald) of 1 week (gratis)

**<span translate="no">Pull Request</span>**&nbsp; (Pull Request): formele methode om wijzigingen aan een repository aan te vragen

**<span translate="no">QR</span>**&nbsp; (QR): een machineleesbare code bestaande uit een reeks zwarte en witte vierkanten

**<span translate="no">repository</span>**&nbsp; (repository): bevat projectbestanden en de revisiegeschiedenis van elk bestand

**<span translate="no">TEAMID</span>**&nbsp; (TEAMID): Één van 6 Secrets: Apple Developer account lidnummer

**<span translate="no">FASTLANE_ISSUER_ID</span>**&nbsp; (FASTLANE_ISSUER_ID): Één van 6 Secrets: de issuer ID is gekoppeld aan uw Apple Developer ID en verandert nooit

**<span translate="no">FASTLANE_KEY_ID</span>**&nbsp; (FASTLANE_KEY_ID): Één van 6 Secrets: Key ID gegeven wanneer u een API key aanmaakt in App Store Connect; het is gekoppeld aan de FASTLANE_KEY

**<span translate="no">FASTLANE_KEY</span>**&nbsp; (FASTLANE_KEY): Één van 6 Secrets: Echt lange sleutel (meerdere regels); het en FASTLANE_KEY_ID worden samen gegenereerd

**<span translate="no">GH_PAT</span>**&nbsp; (GH_PAT): Één van 6 Secrets: Gegenereerd met uw GitHub account; stel het in om nooit te verlopen

**<span translate="no">MATCH_PASSWORD</span>**&nbsp; (MATCH_PASSWORD): Één van 6 Secrets: Git repo encryptie wachtwoordzin, gebruikt om de Match-Secrets repository te versleutelen wanneer deze wordt aangemaakt. U moet hetzelfde MATCH_PASSWORD opslaan en gebruiken voor elke repository als u meerdere apps bouwt.

**<span translate="no">SHA-1</span>**&nbsp; (SHA-1): Secure Hash Algorithm 1; gebruikt om een alfanumerieke code te genereren voor commits in git (github)

**<span translate="no">Terminal</span>**&nbsp; (Terminal): interface voor het invoeren van commando's aan de computer

**<span translate="no">TestFlight</span>**&nbsp; (TestFlight): een methode om apps te distribueren zonder directe verbinding

**<span translate="no">Tooltip</span>**&nbsp; (Tooltip): korte definities gegeven voor belangrijke termen en afkortingen op de website

**<span translate="no">URL</span>**&nbsp; (URL): website adres (Uniform Resource Locator)

**<span translate="no">watchOS</span>**&nbsp; (watchOS): Apple watch besturingssysteem; moet compatibel zijn met telefoon iOS

**<span translate="no">workflow</span>**&nbsp; (workflow): een set instructies voor GitHub om een actie uit te voeren; de instructiebestanden worden gevonden in de .github/workflows map van de repository

**<span translate="no">Xcode</span>**&nbsp; (Xcode): programma gebruikt om een app te bouwen
